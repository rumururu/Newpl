# STAR SETTLERS · 우주 개척단 — 게임 기획서 v1.0

## 1. 한 줄 소개
> 머리 큰 치비 선장이 되어 우주를 누비며 해적을 물리치고, 행성을 개척하고, 우주정거장을 키워 나만의 은하 제국을 만드는 **캐주얼 액션 + 방치형 성장** 모바일 게임.

- **장르**: 탑다운 우주 슈팅 + 개척/경영 + 방치형 수입
- **플랫폼**: Android(Google Play), iOS(App Store). 웹은 데모용
- **타깃**: 10~30대 캐주얼 게이머. 짧은 세션(3~10분)을 자주 하는 모바일 유저
- **레퍼런스 감성**: 윙코맨더(우주 전투·함선), 치비 캐릭터(귀여운 SD), 방치형 게임(오프라인 수입)
- **세션 설계**: 한 번 켜면 "오프라인 수입 수령 → 임무 1~2개 → 업그레이드 → 종료"가 5분 안에 끝나게

## 2. 핵심 재미 (Design Pillars)
1. **손맛 있는 전투**: 조이스틱 하나로 쉽게 조작하고, 미사일·실드·부스트 스킬과 화면 흔들림·데미지 숫자로 타격감을 줌
2. **눈에 보이는 성장**: 식민지 돔이 늘어나고 정거장이 커지고 함선 스킨이 바뀌는 등, 성장이 화면에 그대로 드러남
3. **귀여운 캐릭터**: 선장, 부관 미나, 해적, 그리고 수집하는 승무원 전원이 치비이고, 대사로 성격을 표현함
4. **안 해도 쌓이는 수입**: 접속하지 않아도 식민지가 돈을 벌어 매번 돌아올 이유를 만듦

## 3. 게임 루프
### 3.1 코어 루프 (1~3분)
```
비행 → 전투/채굴 → 💰💎 획득 → 정거장 귀환 → 업그레이드 → 더 강한 적에 도전
```
### 3.2 메타 루프 (하루~주)
```
섹터 개척(정착·정거장) → 수입 증가 → 섹터 두목 격파 → 워프 게이트 해금
→ 다음 섹터(더 강한 적, 더 큰 보상) → 승무원 수집·강화 → 반복
```
### 3.3 리텐션 루프
- **오프라인 수입**: 최대 2시간(프리미엄 8시간)
- **일일 출석**: 7일 주기, 7일차 대박 보상
- **일일 무료 젬**: 광고 시청 시 하루 3회
- **임무 게시판**: 3분마다 새 임무
- **업적**: 15개 이상, 젬 보상

## 4. 콘텐츠 상세
### 4.1 함선과 스킬
| 항목 | 효과 | 최대 레벨 |
|---|---|---|
| 무기 | 공격력 +5/Lv, 연사 +10%, Lv.3에 2연발, Lv.6에 3연발 | 8 |
| 장갑 | 최대 체력 +40/Lv | 8 |
| 엔진 | 최고 속도 +40/Lv | 8 |
| 🚀 유도 미사일 (Q) | 해금 후 Lv당 피해·발사 수 증가, 쿨타임 8초 | 5 |
| 🛡 실드 (F) | 일정 시간 모든 피해 흡수, 쿨타임 18초 | 5 |
| 💨 부스트 (Shift) | 순간 돌진 + 잠깐 무적, 쿨타임 4초 | 기본 제공 |

### 4.2 적
| 적 | 특징 |
|---|---|
| 해적 정찰선 | 빠르고 약함 |
| 해적 습격선 | 균형형 |
| 자폭선 💣 | 돌진해서 자폭하므로 먼저 잡아야 함 |
| 저격선 🎯 | 멀리서 강한 한 방, 거리 유지 |
| 우주 해파리 🪼 | 중립 몬스터. 느리게 떠다니며 접촉하면 피해, 젬을 드롭함 |
| 해적 두목 ☠ | 3연발, 높은 체력. 섹터 두목을 쓰러뜨리면 게이트가 열림 |
| 현상수배범 | 임무로 등장하는 이름 붙은 엘리트 |

### 4.3 개척
- **행성 5종**: 정원(💰), 사막(💰+💎), 얼음(💎+💰), 용암(💎), 가스(💰 대량, 비쌈). 식민지 Lv.1~5
- **정거장**: 거주구역(수입, 내구도), 방어포탑(자동 요격). 해적이 공격하므로 방어가 필요함
- **시장**: 정거장에서 광석을 크레딧으로 판매. 시세는 시간에 따라 변동(싸게 사서 비싸게 파는 재미)

### 4.4 승무원 (수집 요소)
- 직업 6종: 포수(공격력), 기관사(체력·수리), 조종사(속도), 상인(크레딧 수입), 광부(광석), 과학자(스킬 쿨타임)
- 희귀도 ★1~★3, 레벨 1~5. 함선에 3명 배치(젬으로 4번째 슬롯 해금)
- 외형은 랜덤 치비(머리색, 의상, 액세서리)
- **확률 공개**: 크레딧 영입 ★1 70% / ★2 25% / ★3 5%, 젬 영입 ★2 80% / ★3 20%. 게임 안에 항상 표시함(한국 게임산업법 확률형 아이템 표시 의무 대응)

### 4.5 임무
- **스토리 챕터(튜토리얼 겸용)**: 채굴 → 해적 처치 → 정착 → 개조 → 승무원 → 임무 → 정거장 → 두목 → 워프. 부관 미나가 안내함
- **게시판 임무**: 해적 소탕, 광석 수집, 화물 운송(A→B 행성), 현상수배(이름 있는 엘리트 사냥)

### 4.6 랜덤 이벤트 (1.5~2.5분마다)
| 이벤트 | 내용 |
|---|---|
| 🏴‍☠️ 식민지 습격 | 해적이 식민지를 공격하고, 습격 중에는 생산이 중단됨. 막아내면 보상 |
| ☄ 유성우 | 크리스탈 소행성이 대량으로 쏟아짐 |
| 🛒 떠돌이 상인 | 2분 동안 등장. 희귀 승무원, 크레딧→젬 환전, 버프 판매 |
| 📦 보급 캡슐 | 해적이 지키는 젬 캡슐 |

### 4.7 섹터
- 알파 성역 → 베타 성운 → 감마 협곡 → 델타 해적지대 → 엡실론 심연 → … (무한)
- 섹터가 올라갈수록 적 체력·피해와 보상·생산량이 함께 오름
- 다른 섹터의 식민지도 계속 수입을 냄(제국 확장의 쾌감)

### 4.8 파워업 (적 처치 시 드롭)
연사(⚡), 실드(🛡), 자석(🧲), 크레딧 2배(💰x2)

## 5. 수익화 설계
### 5.1 원칙
- **Pay-to-Win 최소화**: 과금은 "시간 단축 + 꾸미기 + 편의" 위주로 하고, 무과금도 모든 콘텐츠를 즐길 수 있게
- **강제 광고 없음**: 전면 광고는 넣지 않고, 유저가 원할 때만 보는 **보상형 광고**만 사용
- **가챠는 최소화**: 유료 랜덤은 젬 승무원 영입 하나뿐이고 확률을 공개함. 꾸미기는 전부 직접 구매

### 5.2 화폐
| 화폐 | 획득 | 사용 |
|---|---|---|
| 💰 크레딧 | 전투, 채굴, 식민지, 임무 | 업그레이드, 정착, 건설, 영입 |
| 💎 광석 | 채굴, 행성 | 업그레이드 재료, 시장 판매 |
| ⭐ 스타젬 (프리미엄) | 업적, 출석, 두목, 보급 캡슐, 광고, **인앱결제** | 스킨, 의상, 부활, 승무원 슬롯, 젬 영입, 크레딧 팩 |

### 5.3 인앱 상품 (가격은 출시 시점에 조정)
| 상품 ID | 이름 | 가격(KRW) | 내용 |
|---|---|---|---|
| `gems_100` | 젬 한 줌 | 1,200 | ⭐100 |
| `gems_550` | 젬 주머니 | 5,900 | ⭐550 (+10%) |
| `gems_1200` | 젬 상자 | 12,000 | ⭐1200 (+20%) |
| `starter_pack` | 스타터 팩 (1회 한정) | 3,900 | ⭐300 + 전용 스킨 "갤럭시" + ★3 승무원 |
| `premium_pass` | 함대 사령관 패스 (영구) | 6,500 | 크레딧 수입 +25%, 오프라인 8시간, 광고 없이 2배 보상, 전용 스킨 "골드 로열" |

### 5.4 보상형 광고 지점
1. 오프라인 수입 2배
2. 격추 시 그 자리에서 무료 부활(크레딧 손실 없음)
3. 일일 무료 젬(하루 3회, 1회 ⭐5)

프리미엄 패스 구매자는 광고 없이 바로 보상을 받음.

### 5.5 기대 지표 (참고용 목표)
- D1 리텐션 35%+, D7 12%+
- 결제 전환율 2~3%, 스타터 팩이 첫 결제 유도
- 광고 ARPDAU는 보상형 광고 시청률 30% 목표

## 6. 기술 구조
- Flutter 단일 코드베이스, 그래픽은 전부 `CustomPainter`(에셋 의존 최소, 앱 용량 작음)
- `GameWorld`(순수 Dart 규칙 엔진)와 UI를 분리해서 단위 테스트 가능
- 저장은 두 종류로 나눔: **월드 저장**(새 게임 시 초기화)과 **프로필 저장**(젬, 구매, 꾸미기, 업적은 새 게임을 해도 유지)
- 결제/광고는 `MonetizationService` 인터페이스로 추상화
  - 개발용: `DevMonetization` (테스트 다이얼로그)
  - 출시용: `in_app_purchase` 연동 + AdMob 보상형 광고 (docs/STORE_RELEASE.md 참고)
- 사운드: 직접 합성한 효과음과 BGM(wav), `audioplayers`
