# 🚀 STAR SETTLERS · 우주 개척단

머리 큰 치비 선장이 되어 우주를 날아다니며 해적과 싸우고, 행성에 정착하고, 우주정거장을 키우는 Flutter 게임입니다.
그래픽은 전부 코드(`CustomPainter`)로 그려서 이미지 에셋 없이 바로 실행됩니다.

## 게임 루프
1. **비행 & 전투**: 해적을 격추하면 💰 크레딧, 소행성을 부수면 💎 광석을 얻어요.
2. **행성 정착**: 행성에 다가가 🚩 정착 → 식민지를 Lv.5까지 키우면 자동 수입이 늘어나요.
3. **정거장 건설**: 빈 우주에서 🏗 정거장 건설 → 거주구역(수입), 방어포탑(자동 요격)을 업그레이드해요.
4. **함선 개조**: 정거장에서 무기(3/6레벨 다연발)·장갑·엔진을 강화해요.
5. **위협 증가**: 시간이 지나고 제국이 커질수록 해적이 강해지고, 위협도 3마다 ☠ 해적 두목이 나타나요.

## 조작
| 동작 | 모바일 | 키보드 |
|---|---|---|
| 이동 | 왼쪽 조이스틱 | WASD / 방향키 |
| 사격 | 발사 버튼 (자동사격 토글) | Space |
| 정착 / 정거장 메뉴 | 화면 버튼 | E |
| 정거장 건설 | 화면 버튼 | B |
| 일시정지 | ⏸ | Esc |

진행 상황은 20초마다, 그리고 업그레이드할 때마다 자동 저장됩니다.

## 실행
```bash
flutter pub get
flutter run            # 연결된 기기
flutter run -d chrome  # 웹
flutter test
```

## 구조
```
lib/
  main.dart               타이틀 화면
  game/models.dart        엔티티(함선, 해적, 행성, 정거장 등)
  game/world.dart         게임 규칙·시뮬레이션 (UI와 분리, 테스트 가능)
  game/save.dart          저장/불러오기 (shared_preferences)
  ui/chibi.dart           치비 캐릭터 페인터 (선장, 해적, 부관 미나)
  ui/world_painter.dart   우주/행성/정거장/함선 렌더링, 미니맵
  ui/game_screen.dart     게임 루프, 조이스틱, HUD, 정거장 메뉴
```
